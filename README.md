# Halal Travel Scout Site

Build a simple, low-maintenance multi-page website (4-5 pages max) for HalalTravelScout, a halal family travel content brand. This site should be "set and forget" — written once, rarely needing updates. Do not build any page that requires frequent content additions (no blog, no live feed, no growing archive).

BRAND IDENTITY
- Name: HalalTravelScout
- Tagline: "Travel · Discover · Verify"
- Bio line: "1 country a week, 1 tip a day — follow the journey"
- Tone: warm, practical, first-person "insider scout" voice — trustworthy, not preachy, not overly formal

VISUAL STYLE
- Colors: deep teal green (#0F5C4A) primary, warm gold (#C9932E) accent, cream/off-white (#FBF3E3) background
- Serif font (like Georgia or Playfair Display) for headings, clean sans-serif for body text
- Clean, modern, trustworthy travel-brand feel

STRICT CONTENT RULE — NON-NEGOTIABLE
- No images, illustrations, icons, or graphics depicting human beings, human faces, or human silhouettes anywhere on the site.
- Use only: landscapes, architecture, food photography, maps, objects, and text-based design elements.

PAGES

1. HOMEPAGE
- Hero: wordmark, tagline, bio line, short intro paragraph about the brand
- Brief section on what "halal travel" means in practice (certified halal food, prayer facilities, family-friendly halal-verified attractions) — written for someone new to the concept
- Trust note: halal guidance reflects personal research; recommend verifying significant matters with qualified scholars
- Link to Instagram (@halaltravelscout)

2. SAMPLE ITINERARIES PAGE (static, written once — not a growing archive)
- 3 illustrative sample itineraries as fixed, evergreen content, for example:
  - "5-Day Family Itinerary: Kuala Lumpur, Malaysia"
  - "4-Day Family Itinerary: Istanbul, Turkey"
  - "3-Day Family Itinerary: Bali, Indonesia" (halal-conscious version)
- Each itinerary: day-by-day structure (Day 1, Day 2, etc.), covering halal food stops, prayer facility notes, and family-friendly attractions
- Frame this page as "example trips to inspire your planning" rather than a live, constantly-updated blog

3. ABOUT PAGE
- Brief brand story: built as a long-term personal project, not a fast-launch business
- What makes it different: verified, checkable information over vague "halal-friendly" labels

4. MEDIA KIT / PARTNER PAGE
- Short summary for hotels/DMCs/tourism boards: niche, target audience, content format, what's offered
- Placeholder fields for audience size and engagement rate (labeled "coming soon" — to be manually updated later)
- Contact section

5. CONTACT PAGE
- Instagram link, contact email
- Keep minimal — no form required unless simple to include

FUNCTIONALITY
- Fully responsive, mobile-friendly
- Simple navigation bar linking all pages
- Minimal animation, fast-loading
- No dynamic/live content anywhere — everything should be static text and images set once at launch

Build this as a clean, professional, low-maintenance static site. All written content should be evergreen — nothing that implies it needs regular updates.
